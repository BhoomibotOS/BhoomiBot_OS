# BhoomiBot AgentOS: Operator's Quick-Start & GUI Guide

This guide explains how to use the **Agent AI** (Layer 0) to control your robot using natural language optimized for Indian agricultural contexts.

---

## 1. GUI Navigation Guide: "Where to Tap"

### Step A: The Connection (Fast-Pair)
1.  **Robot Phone:** Go to `Settings` -> `Live Link` -> Select `Hotspot Mode`.
2.  **Robot Phone:** Turn ON `Local Hub Server` -> Tap **`SHOW PAIRING QR`**.
3.  **Operator Phone:** Go to `Settings` -> `Live Link` -> Select `Hotspot Mode`.
4.  **Operator Phone:** Tap the **`QR Scanner Icon`** and point it at the robot's screen.
5.  **Operator Phone:** Tap **`SAVE & GO LIVE`**.

### Step B: The Hardware Link (VCU)
1.  **Robot Phone:** In `Settings` -> `Connection`, tap the green **`CONNECT`** button.
2.  **Visual Check:** Ensure the top status bar shows **`VCU: Connected`** on both phones.

### Step C: The Agent AI
1.  **Operator Phone:** On the Home Screen, tap the **`Agent AI`** card (✨).
2.  **Operator Phone:** Tap the mic or type your command at the bottom.

---

## 2. Agent AI Cheat Sheet: "Natural Indian English Commands"

The Agent is optimized for local phrasing. You can speak or type naturally.

### A. Core Skills & Help
*   **"Hi"** or **"Namaste"** → Robot introduces itself and shows examples.
*   **"Help"** → Robot lists its capabilities.

### B. Moving the Robot (Navigation)
*   **"Go to the Well side."**
*   **"Drive to the Farm Hub."**
*   **"Reach the Shed area."**

### C. Carrying Loads (Transport)
*   **"Shift the load to the Shed."**
*   **"Take fertilizer to the Mango field."**
*   **"Put the crates in the Loading zone."**
*   **"Move sacks from Shed to Field B."**

### D. Learning & Teaching
*   **"Learn a new zone called Tomato Field."**
*   **"Define this place as Water Tank."**
*   **"Record the path for Point A."**

---

## 3. The "Interactive Teacher" Workflow

If you ask for a place the robot doesn't know (e.g., *"Take fertilizer to North Patch"*):
1.  **Robot:** *"I don't know where 'North Patch' is. Should I learn it now?"*
2.  **You:** Select **`Drive me there to map it`**.
3.  **Action:** Drive the robot to the location.
4.  **Result:** The robot now remembers "North Patch" for all future tasks.

---

## 4. Safety First
*   **Red Button:** Tap **`EMERGENCY STOP`** on the Manual screen to cut power instantly.
*   **Voice Stop:** Say **"Stop now"** or **"Halt"** in the chat for an immediate software-controlled stop.
